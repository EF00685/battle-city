# 坦克大战 · Battle City

一个用原生 HTML + Canvas + JavaScript 编写的经典《坦克大战》（Battle City）复刻，单文件即可运行，无需任何依赖或构建步骤。

## 🎮 玩法

- 控制你的坦克，消灭所有敌方坦克，**保护好你的基地（旗帜）**。
- 基地一旦被摧毁（无论被敌人还是你自己的子弹击中），游戏结束。
- 每清空一关的敌人即可进入下一关，共 3 关。

## 🕹️ 操作

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动 |
| 空格 / `J` | 射击 |
| `M` | 静音 / 取消静音 |
| `P` | 暂停 / 继续 |
| 回车 | 开始 / 重新开始 |

手机触屏设备会自动显示虚拟方向键与射击按钮。

## ✨ 特性

- 三种敌方坦克：普通、快速、重型（重装需要 3 发子弹）
- 三种道具：**★ 火力增强**（子弹可升级至穿钢）、**♥ 加命**、**⛨ 无敌护盾**
- 可破坏的砖墙、不可破坏的钢墙、可穿越的水面、可隐藏的树林
- 多个关卡、得分系统、粒子爆炸特效、Web Audio 音效

## 🚀 运行

直接用浏览器打开 `index.html` 即可，或使用任意静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

也可以直接游玩 GitHub Pages 版本（见仓库页面）。

## 🧱 技术说明

- 纯原生实现，无第三方库
- 640×640 画布，20×20 瓦片地图
- 关卡由 ASCII 地图生成（`#` 砖墙、`@` 钢墙、`~` 水面、`%` 树林）
- 像素级碰撞检测 + 网格对齐移动
